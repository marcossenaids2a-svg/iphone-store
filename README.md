# iPhone Store

Loja virtual demonstrativa de iPhones, feita com HTML, CSS e JavaScript puro.

## Como executar
1. Baixe ou clone este repositório.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador (ou use a extensão Live Server).

## Funcionalidades
- Layout responsivo para celular, tablet e computador.
- Vitrine de produtos.
- Filtro por categoria e busca por modelo.
- Sacola com adicionar, remover e alterar quantidades.
- Cálculo automático do total.
- Formulário demonstrativo de newsletter.

## Personalização
Edite os produtos no início de `script.js` para alterar modelos, descrições, imagens e preços.

> **Aviso:** este projeto é apenas uma demonstração visual. Não processa pagamentos nem registra pedidos reais. Os preços são ilustrativos. As imagens são carregadas de URLs externas.
